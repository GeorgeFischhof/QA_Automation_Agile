# Comprehensive List of UI Widgets (2026)

Here’s a **comprehensive list of UI widgets** categorized by their purpose, including both **traditional** and **modern/advanced** widgets as of 2026. This covers all major UI libraries and frameworks.

---

## 1. Layout Widgets
Widgets that structure and organize content within a UI.

| **Widget**               | **Description**                                                                                                                                                     | **Common Use Cases**                                                                 |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| **Accordion**            | A vertical stack of collapsible panels that expand to show content when clicked.                                                                                   | FAQs, settings panels, dashboards.                                                   |
| **Tabs**                 | Organizes content into multiple panels, each accessible via a tab.                                                                                                 | Multi-page forms, settings windows, IDEs.                                            |
| **Dockable Windows**     | Windows that can be anchored to the edges of the main window or floated freely.                                                                                     | IDEs (VS Code, Visual Studio), advanced text editors.                                |
| **Floating Windows**     | Detachable windows that can be moved independently over the main application.                                                                                       | Tool palettes, property inspectors, pop-up dialogs.                                  |
| **Grid Layout**          | Arranges elements in a grid of rows and columns.                                                                                                                    | Dashboards, data tables, image galleries.                                            |
| **Flexbox Container**    | A container that uses flexible sizing to arrange child elements.                                                                                                    | Responsive layouts, card-based UIs.                                                 |
| **Masonry Grid**         | A grid layout that arranges items in optimal positions based on available vertical space.                                                                         | Image galleries, Pinterest-like layouts.                                             |
| **Split Pane**           | Divides a container into resizable panes.                                                                                                                           | Code editors (split view), file explorers.                                           |
| **Card**                 | A container that groups related content and actions.                                                                                                               | Dashboards, product displays, profile sections.                                      |
| **Modal Dialog**         | A window that appears on top of the main content, requiring user interaction.                                                                                       | Alerts, confirmations, login forms.                                                 |
| **Popover**              | A small overlay that appears when clicking or hovering an element.                                                                                                   | Tooltips, context menus, quick actions.                                             |
| **Sidebar**              | A collapsible panel that slides in from the side of the screen.                                                                                                     | Navigation menus, filters, chat panels.                                              |
| **Hero Section**         | A prominent, full-width section at the top of a page.                                                                                                              | Landing pages, marketing sites.                                                      |
| **Hero Banner**          | A large, visually striking banner, often with a call-to-action.                                                                                                    | Homepages, promotional sections.                                                     |
| **Sticky Header/Footer** | Elements that remain fixed at the top or bottom of the viewport.                                                                                                     | Navigation bars, footers.                                                            |
| **Z-Index Layers**       | Controls the stacking order of elements.                                                                                                                            | Overlays, modals, tooltips.                                                          |
| **Responsive Grid**      | A grid that adapts to different screen sizes.                                                                                                                       | Mobile-first designs, adaptive layouts.                                              |

## 2. Navigation Widgets
Widgets that help users navigate through an application or website.

| **Widget**               | **Description**                                                                                                                                                     | **Common Use Cases**                                                                 |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| **Breadcrumb**           | Shows the user’s location in a hierarchy of pages.                                                                                                                 | E-commerce sites, multi-level dashboards.                                             |
| **Pagination**           | Divides content into discrete pages.                                                                                                                                | Search results, product listings.                                                    |
| **Infinite Scroll**      | Loads content dynamically as the user scrolls.                                                                                                                     | Social media feeds, news sites.                                                      |
| **Dropdown Menu**        | A list of options that appears when clicking a button.                                                                                                             | Navigation menus, form selections.                                                   |
| **Mega Menu**            | A large, multi-column dropdown menu.                                                                                                                                | E-commerce sites, complex navigation.                                                |
| **Hamburger Menu**       | A collapsible menu that appears as a hamburger icon (☰).                                                                                                           | Mobile navigation, responsive designs.                                               |
| **Tab Bar**              | A horizontal bar of tabs for switching between views.                                                                                                              | Mobile apps, settings screens.                                                       |
| **Sidebar Navigation**   | A persistent or collapsible navigation menu on the side of the screen.                                                                                              | Dashboards, admin panels.                                                            |
| **Breadcrumbs**          | Shows the path taken to reach the current page.                                                                                                                    | E-commerce, documentation sites.                                                     |
| **Search Bar**           | A text input field for searching content.                                                                                                                           | Websites, apps with large datasets.                                                 |
| **Autocomplete**         | Suggests search terms or options as the user types.                                                                                                                 | Search engines, form inputs.                                                         |
| **Tree View**            | Displays hierarchical data in a collapsible tree structure.                                                                                                         | File explorers, organizational charts.                                               |
| **Carousel**             | A rotating set of items, often used for images or cards.                                                                                                            | Image galleries, testimonial sections.                                               |
| **Slider**               | A draggable handle for selecting a value or range.                                                                                                                 | Volume controls, image carousels.                                                    |
| **Stepper**              | Guides users through a multi-step process.                                                                                                                          | Checkout forms, onboarding flows.                                                    |
| **Pagination Dots**      | Visual indicators for the current page in a carousel or slider.                                                                                                      | Image sliders, tutorials.                                                            |

## 3. Input Widgets
Widgets that allow users to input data or interact with the application.

| **Widget**               | **Description**                                                                                                                                                     | **Common Use Cases**                                                                 |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| **Text Input**           | A field for entering text.                                                                                                                                         | Forms, search bars.                                                                  |
| **Textarea**             | A multi-line text input field.                                                                                                                                      | Comments, descriptions, long-form inputs.                                            |
| **Checkbox**             | A box that can be toggled on/off.                                                                                                                                   | Multi-select options, toggles.                                                       |
| **Radio Button**         | A set of options where only one can be selected.                                                                                                                   | Single-choice forms (e.g., gender, payment method).                                  |
| **Toggle Switch**        | A switch that toggles between two states (on/off).                                                                                                                 | Settings (e.g., dark mode, notifications).                                           |
| **Dropdown Select**      | A dropdown menu for selecting one or more options.                                                                                                                 | Forms, filters.                                                                       |
| **Multi-Select**         | A dropdown that allows selecting multiple options.                                                                                                                  | Tag selection, advanced filters.                                                     |
| **Date Picker**          | A calendar widget for selecting dates.                                                                                                                              | Booking systems, forms.                                                               |
| **Time Picker**          | A widget for selecting a time.                                                                                                                                      | Scheduling apps, event planners.                                                     |
| **Color Picker**         | A widget for selecting colors.                                                                                                                                      | Design tools, theme customizers.                                                     |
| **File Upload**          | A button or drag-and-drop area for uploading files.                                                                                                                 | Forms, document uploads.                                                             |
| **Range Slider**         | A slider for selecting a range of values.                                                                                                                          | Price filters, volume controls.                                                       |
| **Rating Widget**        | A widget for rating content (e.g., stars, thumbs up/down).                                                                                                           | Reviews, feedback forms.                                                             |
| **Rich Text Editor**     | A text input with formatting options (bold, italic, lists, etc.).                                                                                                   | Blog posts, comments, email editors.                                                 |
| **Autocomplete Input**   | A text input that suggests completions as the user types.                                                                                                           | Search bars, form inputs.                                                            |
| **Password Input**       | A text input that masks entered characters.                                                                                                                         | Login forms, secure inputs.                                                          |
| **OTP Input**            | A set of input fields for entering one-time passwords.                                                                                                              | Two-factor authentication.                                                          |
| **Signature Pad**        | A widget for capturing handwritten signatures.                                                                                                                      | Contracts, approvals.                                                                |
| **QR Code Scanner**      | A widget for scanning QR codes.                                                                                                                                     | Mobile apps, payment systems.                                                        |

| **Widget**               | **Description**                                                                                                                                                     | **Common Use Cases**                                                                 |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| **Table / Data Grid**    | Displays data in rows and columns.                                                                                                                                  | Spreadsheets, admin dashboards.                                                      |
| **List**                 | Displays items in a vertical or horizontal list.                                                                                                                    | Menus, notifications, contact lists.                                                |
| **Card Grid**            | Displays items in a grid of cards.                                                                                                                                  | Product listings, dashboards.                                                        |
| **Progress Bar**         | Shows the progress of a task.                                                                                                                                       | File uploads, loading states.                                                        |
| **Progress Circle**      | A circular progress indicator.                                                                                                                                      | Dashboards, health metrics.                                                          |
| **Sparkline**            | A small, simple chart for displaying trends.                                                                                                                        | Dashboards, financial apps.                                                          |
| **Gauge**                | A widget that displays a value on a dial or meter.                                                                                                                  | Speedometers, battery indicators.                                                    |
| **Timeline**             | Displays events in chronological order.                                                                                                                             | Project management, history logs.                                                    |
| **Calendar**             | Displays dates and events in a calendar format.                                                                                                                     | Scheduling apps, event planners.                                                     |
| **Chart (Bar, Line, Pie)** | Visualizes data using charts.                                                                                                                                       | Dashboards, analytics.                                                               |
| **Map**                  | Displays geographic data.                                                                                                                                           | Location-based apps, delivery trackers.                                              |
| **Image Gallery**        | Displays a collection of images.                                                                                                                                    | Portfolios, product galleries.                                                       |
| **Video Player**         | Embeds and controls video content.                                                                                                                                  | Media players, tutorials.                                                            |
| **Audio Player**         | Embeds and controls audio content.                                                                                                                                  | Music apps, podcast players.                                                         |
| **Badge**                | Small indicators for notifications or status.                                                                                                                       | Notifications, labels.                                                               |
| **Toast Notification**   | A small, temporary notification that appears in the corner of the screen.                                                                                           | Alerts, success/error messages.                                                      |
| **Tooltip**              | A small popup that appears when hovering an element.                                                                                                                | Contextual help, explanations.                                                        |
| **Accordion**            | (Also listed under Layout) A collapsible container for organizing content.                                                                                          | FAQs, settings panels.                                                               |
| **Collapsible Section**  | A section that can be expanded or collapsed.                                                                                                                        | Long forms, detailed views.                                                          |

## 5. Feedback & Interaction Widgets
Widgets that provide feedback or encourage user interaction.

| **Widget**               | **Description**                                                                                                                                                     | **Common Use Cases**                                                                 |
|--------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------|
| **Button**               | A clickable element that triggers an action.                                                                                                                        | Forms, CTAs, navigation.                                                             |
| **Icon Button**          | A button with an icon instead of text.                                                                                                                              | Toolbars, quick actions.                                                             |
| **Floating Action Button (FAB)** | A circular button that floats above the UI, often for primary actions.                                                                                          | Mobile apps (e.g., "Add" button).                                                    |
| **Like/Dislike Button**  | Buttons for expressing preference (e.g., thumbs up/down).                                                                                                          | Social media, reviews.                                                               |
| **Share Button**         | A button for sharing content.                                                                                                                                       | Social media, blogs.                                                                |
| **Drag-and-Drop Zone**   | A designated area for dragging and dropping items.                                                                                                                 | File uploads, kanban boards.                                                         |
| **Confirmation Dialog**  | A modal that asks for user confirmation before proceeding.                                                                                                          | Deleting items, form submissions.                                                    |
| **Alert**                | A modal that displays important information or warnings.                                                                                                            | Errors, system messages.                                                             |
| **Loading Spinner**      | A widget that indicates a loading state.                                                                                                                            | Async operations, data fetching.                                                     |
| **Skeleton Loader**      | A placeholder that mimics the structure of content while it loads.                                                                                                 | Improves perceived performance in dashboards.                                         |
| **Pull-to-Refresh**      | A gesture that refreshes content when pulled down.                                                                                                                 | Mobile apps (e.g., Twitter, Instagram).                                               |
| **Infinite Scroll Loader** | Indicates that more content is loading as the user scrolls.                                                                                                         | Social media feeds, news sites.                                                      |
